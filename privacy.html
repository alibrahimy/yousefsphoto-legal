Privacy Policy

yousef-os · last updated 22 October 2026

yousef-os is a personal tool used only by the owner of the TikTok account @yousefsphoto. It is not offered to anyone else.

What it accesses

With the owner's permission (TikTok Login Kit), it receives an access token for @yousefsphoto with the user.info.basic and video.upload scopes. It uses them only to upload videos the owner chooses to his own TikTok inbox as drafts, which he then edits and posts himself in the TikTok app.

What it stores

The token is stored only on the owner's own computer, in a file readable only by him. No video, profile data or token is sent to any server other than TikTok's own API.

What it does not do

It does not collect, sell or share personal data, does not track anyone, and has no other users.

Removing access

Access can be revoked at any time in TikTok: Settings and privacy → Security → Manage app permissions.

Contact: @yousefsphoto on TikTok.
